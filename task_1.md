# Задание 1

Сделайте библиотеку для работы с таблицей в памяти, по смыслу близкую к упрощённому фрагменту СУБД. Таблица имеет набор столбцов фиксированных типов: целое, вещественное, строка. Другой проект должен уметь создать пустую таблицу с заданной схемой, вставить строку, получить все строки, выполнить выборку по простому условию (имя столбца, оператор сравнения, значение), узнать число строк после фильтрации.

## Архитектура проекта

### 1. Header-only часть
* Представление ячейки.
* Представление строки.
* Коды ошибок:
  * неизвестный столбец;
  * несовпадение типа;
  * пустое условие.
* Разбор простого условия фильтра из строки.

### 2. Статическая часть
* Хранение данных.
* Вставка строк.
* Полная выборка.
* Выборка с условием.
* **Ограничение:** обращений к диску и консоли быть не должно.

### 3. Динамическая часть (DLL)
* Загрузка таблицы из CSV (первая строка — имена столбцов, далее — данные).
* Сохранение таблицы в CSV.
* *При желании:* дозапись операций в текстовый журнал.

### 4. Демо-приложение
Связывает модули между собой:
* Заполнение таблицы через API статики.
* Выборка данных.
* Сохранение и повторная загрузка через DLL.
* Вывод краткой сводки на экран.

## Тестирование

### Тесты
* Пустая таблица.
* Несколько вставок.
* Фильтр по каждому типу столбца.
* Неверное имя столбца в условии.
