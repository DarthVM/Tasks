# Задание 8. Библиотека классов планарной геометрии и эскизов

Библиотека предоставляет набор классов для работы с геометрическими объектами на плоскости и класс-композит для управления коллекцией фигур. Каждый класс размещается в одноименном заголовочном файле.

## Архитектура проекта

### 1. Header-only часть
* **Точка (Point):** координаты для двумерного пространства (private), создание без параметров запрещено, чтение и изменение координат, евклидово расстояние между точками, вывод информации о точке в формате `"{x,y}"`.
* **Плоская фигура (Figure2D):** опорная точка (protected), создание на основе опорной точки. Абстрактные функции: вывод информации о фигуре (тип фигуры, координаты опорной точки и всех вершин), перемещение фигуры в заданную точку, поворот фигуры на заданный угол в радианах, подсчет площади, подсчет периметра.
* **Наследники (Rect, Circle, Triangle, Pentagon, Hexagon, Octagon):** хранилище координат вершин, создание по геометрическим параметрам (стороны, радиус вписанной/описанной окружности) и точке-центру. Переопределение всех абстрактных функций базовой фигуры.
* **Эскиз (Draft):** хранилище указателей на фигуры, максимальная вместимость, текущее количество элементов. Функции: создание с начальной вместимостью, получение количества фигур, универсальная функция добавления фигуры, доступ к фигуре по индексу, вывод информации об эскизе в консоль, очистка памяти.

### 2. Статическая часть
* Математический расчет координат вершин многоугольников на основе центра и радиуса.
* Геометрические алгоритмы вычисления площадей и периметров для каждого типа фигуры.
* Логика трансформации: пересчет координат вершин при перемещении опорной точки и при вращении вокруг центра.
* Внутренний механизм автоматического увеличения размера хранилища эскиза вдвое с сохранением уже добавленных данных.

### 3. Динамическая часть (DLL)
* Чтение набора геометрических объектов и параметров их создания из текстового файла.
* Запись полной ведомости эскиза (список фигур, координаты всех вершин, площади, периметры) в выходной текстовый файл.

### 4. Демо-приложение
Связывает модули между собой:
* Создание пустого эскиза и наполнение его разными фигурами (минимум 3 разные фигуры).
* Вывод общей сводки по всему эскизу на экран.
* Модификация одной фигуры из эскиза через доступ по индексу: перемещение, поворот на заданный угол.
* Повторный вывод обновленной информации о данной фигуре на экран.
* Сохранение итоговой ведомости эскиза в файл через DLL.

## Тестирование

### Тесты статики
* Запрет создания точки без координат.
* Расчет расстояния между точками на эталонных значениях.
* Проверка формул площади и периметра для всех типов фигур по тестовым координатам.
* Контроль координат вершин после перемещения и поворота фигуры.
* Автоматическое расширение хранилища эскиза при превышении начальной емкости.
