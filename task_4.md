# Задание 4. Библиотека решения систем линейных уравнений (линейная алгебра)

Библиотека решает систему Ax = b квадратного вида (размер n×n) методом Гаусса с выбором главного элемента. Другой проект должен передать матрицу и вектор, получить вектор решения или признак вырожденности, а также оценить невязку r = Ax − b после решения.

## Архитектура проекта

### 1. Header-only часть
* Представление матрицы (размер и доступ к элементам).
* Представление вектора (размер и доступ к элементам).
* Результат решения:
  * успех;
  * вырожденность;
  * код ошибки размерности.

### 2. Статическая часть
* Элементарные операции над матрицей и вектором.
* Решение системы методом Гаусса с выбором главного элемента.
* Вычисление вектора невязки.
* **Ограничение:** без работы с файлами.

### 3. Динамическая часть (DLL)
* Чтение матрицы и правой части из текстового или CSV-файла.
* Запись вектора решения и невязки в выходной текстовый файл.

### 4. Демо-приложение
Связывает модули между собой:
* Чтение входного файла через DLL.
* Решение системы в статике.
* Вывод отчета на экран и запись результатов в файл через DLL.

---

## Тестирование

### Тесты статики
* Система 2×2 с известным ответом.
* Система 3×3.
* Единичная матрица в качестве коэффициентов.
* Вырожденная система уравнений.
* Проверка невязки (значение меньше порога на хорошо обусловленном примере).
* Ошибка несовпадения размеров матрицы и вектора.
