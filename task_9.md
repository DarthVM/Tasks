# Задание 10. Библиотека анализа стержневых систем при растяжении-сжатии

Библиотека для прочностного расчета ступенчатого бруса (стержня), работающего на растяжение или сжатие под действием осевых сил. Брус состоит из нескольких последовательных участков, каждый из которых имеет свою длину, площадь поперечного сечения и материал. Нужно определить внутренние продольные силы на каждом участке, вычислить возникающие механические напряжения и выдать заключение о прочности.

## Архитектура проекта

### 1. Header-only часть
* **Ступень бруса (Section):** длина, площадь поперечного сечения, допускаемое напряжение материала.
* **Внешняя сила (Force):** точка приложения (номер узла) и величина силы (положительная — растягивает, отрицательная — сжимает).
* **Результат расчета участка:** величина внутренней продольной силы, значение механического напряжения, статус прочности (прочно / разрушается).
* **Коды ошибок:** невалидные геометрические размеры (нулевая длина или площадь), привязка силы к несуществующему узлу бруса.

### 2. Статическая часть
* Хранение геометрии ступенчатого бруса и списка приложенных сил в памяти.
* Расчет внутренних продольных сил методом сечений (для консольно закрепленного бруса).
* Вычисление механических напряжений по формуле $\sigma = F / A$.
* Проверка условия прочности: сравнение расчетного напряжения с допускаемым ($|\sigma| \le [\sigma]$).

### 3. Динамическая часть (DLL)
* Импорт параметров бруса и внешних нагрузок из текстового или CSV-файла.
* Экспорт результатов расчета в текстовый файл в виде структурированного отчета (таблица участков: сила, напряжение, коэффициент запаса, итоговый статус).

### 4. Демо-приложение
Связывает модули между собой:
* Загрузка исходных данных расчетной схемы стержня из файла через DLL.
* Вызов расчетного ядра в статической библиотеке.
* Вывод на экран краткой сводки: максимальное возникшее напряжение и общая оценка (выдержит ли брус заданную нагрузку).
* Сохранение подробного инженерного отчета в файл через DLL.

---

## Тестирование

### Тесты статики
* Брус из одной ступени под действием одной растягивающей силы (базовый случай).
* Брус из нескольких ступеней с силами, направленными в разные стороны (взаимное компенсирование нагрузок).
* Проверка участка с нулевой площадью сечения (обработка деления на ноль).
* Тест условия прочности: случай, когда напряжение строго равно допускаемому, и случай явного превышения (разрушение).
