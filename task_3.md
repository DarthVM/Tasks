# Задание 3. Библиотека графа и кратчайшего пути (теория графов)

Библиотека для ориентированного взвешенного графа: добавление вершин и рёбер, запрос кратчайшего пути между двумя вершинами, восстановление последовательности вершин на пути, признак недостижимости. Алгоритм выберите самостоятельно.

## Архитектура проекта

### 1. Header-only часть
* Ребро.
* Результат поиска пути:
  * длина;
  * достижимость;
  * список вершин.
* Коды ошибок:
  * нет вершины;

### 2. Статическая часть
* Представление графа в памяти.
* Алгоритм поиска кратчайшего пути.

### 3. Динамическая часть (DLL)
* Чтение графа из текстового файла (число вершин, число рёбер, далее тройки «из, в, вес»).
* Запись результата пути в текстовый файл (длина и список вершин).

### 4. Демо-приложение
Связывает модули между собой:
* Чтение файла графа и загрузка через DLL.
* Поиск кратчайшего пути в статике.
* Вывод результата на экран и запись в файл через DLL.

---

## Тестирование

### Тесты статики
* Граф из одной вершины.
* Две вершины без ребра.
* Простой путь.
* Несколько путей (выбирается кратчайший).
* Недостижимость вершины.
