# Задание 2. Библиотека разбора и вычисления выражений (формальные языки)

Библиотека для арифметических выражений в строке: числа, скобки, операции сложения, вычитания, умножения, деления; по согласованию с преподавателем — одна буквенная переменная с подстановкой значения. Результат — число или сообщение об ошибке с указанием позиции в строке.

## Архитектура проекта

### 1. Header-only часть
* Токен.
* Тип операции.
* Узел дерева разбора.
* Результат разбора и вычисления:
  * успех;
  * код ошибки;
  * позиция в строке.

### 2. Статическая часть
* Разбиение на токены (лексический анализ).
* Построение дерева разбора (синтаксический анализ).
* Вычисление по дереву.

### 3. Динамическая часть (DLL)
* Подключение набора дополнительных функций (например, синус, косинус, квадратный корень).
* Имена функций при вычислении разрешаются через DLL.

### 4. Демо-приложение
* Ввод выражения с консоли $\rightarrow$ вывод результата.
* Отдельный пример с вызовом функции из DLL.

---

## Тестирование

* Приоритет операций.
* Скобки.
* Деление на ноль.
* Пустая строка.
* Лишний символ.
* Переменная (если разрешена).
