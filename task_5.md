# Задание 5. Библиотека сравнения двух текстов построчно

Библиотека сравнивает две версии текста как две последовательности строк (изменённый конфиг, две выгрузки лога, два списка команд). Нужна сводка: сколько строк совпало, сколько только в первом варианте, сколько только во втором; Алгоритм выберите сами

## Архитектура проекта

### 1. Header-only часть
* Статус строки (совпала / только слева / только справа).
* Сводка сравнения (количество совпавших, уникальных слева и уникальных справа строк).
* При необходимости — одна запись построчного отчёта.

### 2. Статическая часть
* Сравнение двух контейнеров строк в памяти.

### 3. Динамическая часть (DLL)
* Чтение двух текстовых файлов.
* Запись человекочитаемого отчёта `.diff.txt` (заголовок, сводка, список отличий).

### 4. Демо-приложение
Связывает модули между собой:
* Чтение двух файлов через DLL.
* Вызов функции сравнения в статике.
* Вывод краткой сводки на экран.
* Запись полного отчёта через DLL.

---

## Тестирование

### Тесты статики
* Идентичные списки строк.
* Добавлена одна строка в конце.
* Удалена строка в середине.
* Изменена одна строка.
* Один файл пустой.
* Оба файла пустые.
